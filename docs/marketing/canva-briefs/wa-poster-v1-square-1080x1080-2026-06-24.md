## 7. Canva execution checklist

1. **Buka Canva → Create design → Instagram Post** (otomatis 1080×1080)
2. **Brand kit aktifkan** (sudah setup waktu banner)
3. **Background:** Apply navy `#0B2545` ke full canvas
4. **Zone A elements:**
   - Promo badge pill kanan-atas
   - Hero question 2 baris (Inter Black 900, 72px, baris 2 kuning)
5. **Zone B elements:**
   - Stat "80%" CENTER, Inter Black 900, 240px, kuning — ini hero visual
   - Stat description 2 baris di bawahnya
   - Divider 2px kuning di bottom zone
6. **Zone C elements:**
   - VOSI label kiri-atas zone
   - Tagline solution muted slate
   - CTA "Demo gratis 15 menit" kuning bold
   - WA number bold white besar
   - QR code 140×140px di pojok kanan-bawah
7. **Test scroll-stop:** Preview Canva → scroll cepat lihat poster tetap "berhenti" Anda di "80%" yang besar (visual hierarchy test)
8. **Download:**
   - **PNG** kalau quality priority (file 500KB-1MB)
   - **JPG** kalau filesize priority untuk WA broadcast bulk (file 200-400KB)
9. **Filename:** `vosi-wa-poster-quote-hilang-2026-06-24.png`

## 8. WA blast distribution playbook

Sekali poster siap, gunakan dengan WA caption dari pack §10 (long-edukasi 200 kata atau short 50 kata).

### Distribution channels:

| Channel | Format | Frequency |
|---------|--------|------------|
| **WA broadcast list** Anda (network pribadi) | Poster image + caption text dari pack §10 "long-edukasi" | Sekali wave, follow-up 1-2 minggu kemudian "short" version |
| **WA Status / IG Story** | Poster image only, full-screen swipe-up | Daily rotation (24-jam expiry, tidak spam) |
| **IG Post / IG Carousel** | Poster sebagai cover, slide 2-5 elaborate value props | Once posted, evergreen content |
| **TikTok image post** (optional) | Same poster as static image | Test if traction |

### A/B test sederhana di M2:

- Wave 1 (week 1): Poster V1 (80% stat angle) + caption long-edukasi
- Wave 2 (week 3): Poster V2 (different angle — e.g., "Owner pulang jam 6") + caption shorter

Track via Canva analytics + click-through to WA — measure mana yang bring more demo requests.

## 9. QA checklist sebelum send

- [ ] Stat "80%" SANGAT prominent — bisa kebaca di thumbnail size 200×200 px (scroll test)
- [ ] Hero question baris ke-2 "lupa di-follow up?" pakai kuning, baris ke-1 tetap putih — visual hierarchy
- [ ] WA number sudah replace placeholder
- [ ] QR code scannable (test scan di HP teman)

- [ ] Filesize <500 KB untuk WA broadcast efisien
