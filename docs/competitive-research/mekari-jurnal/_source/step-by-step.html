Step-by-Step Guide
Mekari Jurnal Sales Demo

Tujuan dokumen: Panduan lengkap dari sebelum, selama, dan sesudah demo Mekari Jurnal sales call — siap dieksekusi tanpa support live.
Total waktu kamu: ~2 jam tersebar 2–3 hari.
Total biaya: Rp 0.
Dokumen pendamping: 2-probing-questions.docx di folder yang sama (script pertanyaan).
Big picture timeline:
  1. Hari 1 (15 menit): Setup tools, daftar demo, jadwalkan waktu
  2. Hari 2 (60 menit): Eksekusi demo + record
  3. Hari 3 (45 menit): Extract screenshot + transcribe + upload + lapor ke Claude

PHASE 1 — Pre-Demo Setup (Hari 1, ~15 menit)

1Install Tools yang Diperlukan

1.1 — Cek tools yang sudah ada di Mac kamu

Buka Terminal (Cmd+Space → ketik "Terminal" → Enter), copy-paste perintah ini lalu Enter:

which textutil ffmpeg python3 ls /Applications | grep -i -E "zoom|meet|quicktime|obs"

Harusnya muncul minimal: /usr/bin/textutil (built-in), python3 (built-in), dan QuickTime Player.app (built-in). Kalau muncul ffmpeg juga, bagus.

1.2 — Install yang belum ada

ToolUntuk apaCara install
Zoom Desktop Sales Mekari biasanya kasih link Zoom. Punya built-in local recording + auto-transcript. Download di zoom.us/download → install. Free account cukup.
MacWhisper (rekomendasi untuk transcribe) Transcribe audio Indonesia dengan akurasi tinggi, offline (privacy aman). Free. Download di goodsnooze.gumroad.com/l/macwhisper → klik "I want this" → bayar $0 → download .dmg → drag ke Applications.
ffmpeg (opsional, kalau mau extract video frames) Convert video MP4 ke serangkaian PNG frame. Buka Terminal, jalankan: brew install ffmpeg. (Kalau brew belum ada: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)")
Tips: Kalau tidak mau install MacWhisper, pakai Zoom auto-transcript (built-in di Zoom record). Atau Otter.ai (web, free 300 menit/bulan).

2Siapkan Identitas untuk Daftar Demo

Mekari sales akan follow-up via WA + email berbulan-bulan setelah demo. Pakai akun "cadangan" supaya tidak ganggu komunikasi utama.

ItemSaran
EmailBikin Gmail baru gratis (mis. vosi.research+mekari@gmail.com) atau pakai Gmail alias (semua email ke tonywei+mekari@gmail.com tetap masuk ke inbox tonywei@gmail.com kamu).
Nomor WAPakai nomor WA cadangan (Google Voice, Telkomsel Halo cadangan, atau nomor pribadi yang siap di-spam follow-up).
Nama bisnisSebut nama toko istri di LTC ("Toko Material XYZ" — gak perlu real exact, sales tidak verifikasi).
Budget"Rp 500k–1jt/mo" — ini trigger sales demo Essentials + Mekari POS combo, paket paling relevan untuk benchmark.

3Daftar Demo di Website Mekari Jurnal

  1. Buka www.jurnal.id di browser.
  2. Cari tombol "Coba Gratis", "Jadwalkan Demo", atau "Hubungi Sales" — biasanya di kanan atas atau tengah hero section.
  3. Isi form dengan identitas cadangan di step 2.
  4. Pilih waktu demo: siang/sore weekday (Selasa–Kamis, jam 13:00–16:00 WIB). Sales paling responsif dan energi terbaik di window ini.
  5. Submit. Tunggu konfirmasi WA atau email dari sales dalam 1×24 jam.
Hati-hati: Mekari sales kadang langsung telepon dalam 30 menit dari form submission. Kalau kamu tidak siap angkat, set telepon ke silent dan biarkan voicemail — nanti follow-up via WA.

4Konfirmasi Slot Demo + Check Recording Setup

Setelah sales kasih link Zoom/Meet:

  1. Test buka link di hari yang sama supaya yakin tidak ada masalah akses.
  2. Cek mic + camera berfungsi.
  3. Kalau Zoom: buka Settings → Recording → toggle ON "Audio transcript" dan "Record on this computer".
  4. Cek free disk space di Mac ≥ 5 GB (1 jam recording HD ~2 GB).

5Persiapan H-1

  1. Print atau buka di tablet: 2-probing-questions.docx (file pendamping di folder yang sama).
  2. Siapkan notepad fisik atau Notes app untuk catat angka penting yang sales sebut.
  3. Charge laptop / colok ke listrik supaya tidak mati di tengah demo.
  4. Tutup app yang berisik (notifikasi Slack, email pop-up) supaya tidak distract dan tidak terekam.

PHASE 2 — Eksekusi Demo (Hari 2, 45–60 menit)

6Sebelum Sales Connect

  1. Buka file probing questions DOCX di side-by-side dengan window Zoom (split screen).
  2. Buka Notes app untuk catat angka live.
  3. 5 menit sebelum waktu meeting: join Zoom room, test audio.
  4. Mulai recording sebelum sales join (klik tombol Record di Zoom toolbar). Lebih aman over-record daripada lupa.

7Sales Join → Disclose Recording

Setelah sales connect dan greet:

Skrip pembuka (santai, casual):

"Mas/Mbak, makasih ya udah luangkan waktu. Sebelum mulai, izin aku rekam meeting ini buat catatan internal — supaya nanti aku gak lupa detail fitur yang dijelasin. Boleh ya?"

Sales pasti setuju. Ini standard practice dan secara legal Indonesia 1-party consent (kamu peserta, jadi sah).

8Pacing Demo (45–60 menit)

MenitAktivitasYang kamu lakukan
0–5Intro + sales tanya bisnis kamuCerita persona ("toko material istri di LTC, mau digitalisasi karena chat WA banyak"). Tidak perlu detail.
5–25Sales screen-share demoDiam dengarkan + catat. Sales akan auto-cover banyak item dari script kamu. Centang yang sudah dijelaskan di file probing questions.
25–45Q&A — kamu yang driveBuka file probing questions, tanya kategori per kategori dari pertanyaan ★★★ WAJIB yang belum di-cover. Prioritas: Pricing → User → POS integration → WhatsApp → Accounting.
45–60Closing + sales push closingTanya 2 pertanyaan menyentil (#36, #37). Sales mulai push "kapan bisa start?" — jawab "Saya pelajari dulu material yang Mas/Mbak kirim, nanti aku follow-up via email dalam 1 minggu."

9Trick selama Live Demo

"Boleh saya lihat di screen?" — Setiap kali sales jawab "ya bisa" untuk fitur tertentu, follow-up dengan: "Boleh saya lihat di screen sekarang?" Jawaban verbal seringkali tidak match realitas UI.
Repeat angka untuk catat: Saat sales sebut angka spesifik (max produk, harga setelah diskon, limit), ulangi angkanya keras-keras ke sales: "Jadi tier Essentials max 5.000 produk ya? Saya catat untuk perbandingan." Ini double-purpose: (a) memastikan angka kamu akurat, (b) menginformasikan sales kamu serius, dan (c) yang paling penting — kalau besok angkanya beda kamu punya bukti rekaman.
Trigger harga real: Saat sales jelaskan fitur sudah selesai, tanya: "Oke fitur jelas. Kalau saya ambil sekarang annual Plus + POS, harga finalnya berapa setelah semua diskon?" — sales akan kasih angka yang tidak ada di website (biasanya 25–40% lebih murah).
Jangan langsung commit: Sales akan push closing di akhir ("kalau ambil sekarang ada bonus X"). Selalu jawab: "Saya konsultasi sama istri/partner dulu, follow-up via email dalam 3–7 hari ya." Tahan diri — kamu di sini untuk intel, bukan beli.

10Setelah Sales Selesai

  1. Stop recording di Zoom (klik Stop Recording).
  2. Tunggu Zoom render video (sekitar 30–60 detik untuk recording 1 jam). File akan tersimpan di ~/Documents/Zoom/[tanggal]-[meeting-name]/.
  3. Cek folder Zoom — harusnya ada minimal: audio_only.m4a, recording.mp4, dan kalau auto-transcript aktif: audio_transcript.vtt.
  4. Catat di Notes: 3 takeaway paling penting selagi masih segar (mis. "harga real Essentials Rp 300k after annual discount", "tidak punya AI native, harus Qontak terpisah Rp 400k/user").

PHASE 3 — Post-Demo Processing & Upload (Hari 3, ~45 menit)

11Extract Screenshot dari Recording

Cara cepat (rekomendasi) — pause & screenshot manual

  1. Buka file recording.mp4 di QuickTime Player.
  2. Putar dari awal. Setiap kali ada screen sales yang menampilkan fitur penting, pause (spacebar).
  3. Screenshot pakai Cmd+Shift+4 → drag selection di area konten (skip Zoom UI).
  4. Save ke folder: /Users/tonywei/IdeaProjects/ERPAntigravity/docs/competitive-research/mekari-jurnal/results/screenshots/
  5. Rename file deskriptif, contoh:
    • 01-pricing-essentials-list.png
    • 02-stock-create-form.png
    • 03-user-permission-matrix.png
    • 04-pos-integration-diagram.png
    • 05-whatsapp-invoice-flow.png
    • 06-laporan-list.png
    • 07-mobile-app-screenshot.png
    • ...

Target: 30–50 screenshot. Setiap screen fitur yang berbeda, capture 1×. Skip screen yang cuma menu navigasi atau loading.

Cara alternatif — extract semua frame video (kalau mau full coverage)

Buka Terminal, ganti recording.mp4 dengan path file kamu:

cd /Users/tonywei/IdeaProjects/ERPAntigravity/docs/competitive-research/mekari-jurnal/results/frames ffmpeg -i ~/Documents/Zoom/[folder]/recording.mp4 -vf fps=1/15 frame_%04d.png

Hasilnya: 1 frame per 15 detik = ~240 frame untuk recording 1 jam. Lebih comprehensive tapi heavy untuk processing.

12Transcribe Audio

Cara A — MacWhisper (rekomendasi, gratis, offline, akurat untuk Indonesia)

  1. Buka MacWhisper app.
  2. Klik "Drop a file here" atau drag file audio_only.m4a dari Zoom recording folder.
  3. Settings: pilih model "Medium" atau "Large-v3" (lebih akurat, processing lebih lama). Language: pilih Indonesian.
  4. Klik Transcribe. Tunggu 5–15 menit (tergantung CPU).
  5. Hasil transcript muncul di window. Klik Export → Plain Text (.txt).
  6. Save sebagai: /Users/tonywei/IdeaProjects/ERPAntigravity/docs/competitive-research/mekari-jurnal/results/transcript.md

Cara B — Zoom auto-transcript

Kalau kamu sudah enable "Audio transcript" di Zoom settings pre-call, di folder recording akan ada file audio_transcript.vtt.

  1. Buka file .vtt di TextEdit (kanan-klik → Open With → TextEdit).
  2. Copy semua content.
  3. Paste di file baru transcript.md di folder docs/competitive-research/mekari-jurnal/results/.
Catatan: Zoom auto-transcript akurasi Bahasa Indonesia kadang lemah. Kalau hasilnya banyak "[inaudible]" atau ngaco, fallback ke MacWhisper.

13Catat Brochure/Email Follow-up Sales

Sales biasanya kirim follow-up email dalam 2–24 jam berisi proposal, brochure, atau pricing detail. Save semua:

  1. Email body → copy paste ke file follow-up-email.md di folder demo.
  2. PDF attachment → save langsung sebagai brochure.pdf.
  3. Pricing quote screenshot → save sebagai pricing-quote.png.

14Tulis Notes Personal (highlight insight live)

Buka text editor, tulis catatan singkat tentang impression kamu live. Save sebagai notes.md di folder demo:

## Mekari Jurnal Demo — Notes Tanggal demo: [tanggal] Sales: [nama sales] ### Top 3 takeaway 1. ... 2. ... 3. ... ### Angka yang penting - Harga Essentials after annual discount: Rp ... - Setup fee: Rp ... - Max user Essentials: ... - Max produk: ... ### Fitur yang Mekari KUAT - ... ### Fitur yang Mekari LEMAH (gap intel) - ... ### Quote sales yang notable - "..." - "..." ### Pertanyaan yang BELUM ditanya (followup) - ...

Troubleshooting Umum

MasalahSolusi
Zoom recording corrupted / tidak bisa dibuka Buka Zoom → Settings → Recording → klik Local Recording → Open. Kalau folder ada tapi file rusak, biasanya Zoom punya fitur Convert. Atau pakai VLC untuk play file .zoom intermediate.
MacWhisper crash / hang di file besar Pisah file audio jadi 2 part pakai QuickTime (Cmd+T untuk trim), transcribe satu-satu.
Sales tidak share screen, cuma ngobrol Mintabaik-baik: "Mas/Mbak, bisa demo langsung di system supaya lebih jelas?" Kalau tetap tidak mau, akhiri call sopan, jadwalkan ulang dengan sales lain.
Sales agresif minta closing Konsisten jawab: "Saya butuh diskusi dengan istri/partner dulu, follow-up email dalam 3 hari." Jangan kasih card credit / commit apapun.
Lupa enable recording, sudah demo separuh jalan Start recording sekarang juga. Setengah recording lebih baik dari nol. Catat manual untuk separuh awal yang miss.
Screenshot blurry karena Zoom video compression Sales pasti akan kirim brochure PDF di follow-up email. Andalkan PDF untuk detail UI yang blur di video.
