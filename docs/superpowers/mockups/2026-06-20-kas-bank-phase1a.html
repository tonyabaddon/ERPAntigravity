3. Modal — Tambah / Edit akun

Owner only · Dari M1 "+ Tambah Akun" / M2 "✏ Edit"

Account type dropdown menentukan field mana yang muncul. Opening balance + tanggal cuma diminta saat create, tidak bisa diedit setelahnya (kalau salah, owner pakai Penyesuaian di Phase 2). Toggle "Tampilkan di Invoice" cuma muncul untuk type=BANK.

Tambah Akun — Type: BANK

Bank kategori standar

Yang tampil di Invoice PDF ke customer

Buat memudahkan ID di UI kita

"Pribadi owner" akan di-tag chip Pribadi + exclude dari laporan bisnis

Default 0 — bisa di-adjust nanti via Penyesuaian (Phase 2)

Tambah Akun — Type: E-WALLET

Field bank disembunyikan, provider dropdown muncul

Untuk E-Wallet: input saldo terkini sekarang. Phase 2 baru ada Top Up + Spend.

Field "Bank", "Nomor rekening", "Nama di buku tabungan", "Tampilkan di Invoice" — disembunyikan untuk type E-Wallet
