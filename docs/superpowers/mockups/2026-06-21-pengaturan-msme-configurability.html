▶ Pengaturan lanjutan
Per-gate verification method · approver role · self-bypass · reason text

Override verification method per gate (mis. refund pakai WA, tapi opname pakai PIN). Override approver role (default Owner; bisa di-relax ke Staff Admin Toko untuk gate tertentu). Self-bypass (Owner sendiri minta → auto-approve own). Reason required (requestor wajib tulis alasan text).

Pengaturan ini untuk advanced users — 90% tenant cukup pakai checkbox + threshold di atas.

📚 Regulasi yang berlaku (2026)
  • UU HPP No. 7/2021 + PMK 131/2024 — PPN umum 11%, mewah 12% (per Des 2024)
  • PP 55/2022 — PPh Final UMKM 0.5%, batas waktu PT 3thn / CV 4thn / OP 7thn
  • Peraturan DJP Juli 2024 — NIK = NPWP untuk Orang Pribadi
  • e-Faktur 3.0 — mandatory untuk PKP
  • Coretax Administration System (DJP 2025) — pelaporan terpusat (integrasi V2)

Catatan untuk founder review

  • ✅ Pola kartu bahasa-manusia — judul jelas, satu kalimat penjelasan, impact preview (saat ini X, kalau mati Y), inline config (dropdown/threshold).
  • ✅ Autosave + audit log — tidak ada tombol Simpan; setiap toggle commit dengan undo toast 5 detik.
  • ✅ Search across settings — Cmd/Ctrl+K cari setting by keyword (di Frame 1 landing).
  • ✅ Pengaturan lanjutan di-collapse — advanced fields (verification method per gate, approver role, self-bypass) di details, default tertutup.
  • ✅ Pajak 2026 fully aware — UMKM expiry tracker, NIK=NPWP toggle, PKP rate split (11% umum / 12% mewah), placeholder e-Faktur + Coretax.
  • ✅ Garindo seed = zero behavior change — semua existing approval gate tetap "PIN required", Pembelian 7 gate default OFF, modul semua ON, pajak UMKM Final 0.5%.
  • ⚠️ Yang BELUM di mockup ini — wizard first-run 6-step (defer V2), Settings Library full search-and-cards refactor (defer V2), template editor (defer V2).
  • ⚠️ Setting screen existing yang tidak diutak-atik — Umum (Identitas Toko, Jam Operasional, Rekening Bank, Logo, WA Recipients, Costing Method), Notifikasi, WhatsApp AI, Kanal Penjualan. Tetap pakai pattern lama supaya tidak ada regresi.
