Cari by Foto (CLIP)

  • Pipeline: CLIP ViT-Base-32 local (ONNX di backend-go), no Gemini call
  • 3 entry: Kamera + Upload File + drag-drop zone
  • Cold start UX: banner inline "⏱️ Menyiapkan AI… 5 detik"
  • Drop tombol "Generate dari Foto" (zero Gemini dep)
  • Future hybrid (CLIP+Gemini re-rank) defer kalau akurasi < 80%
  • Cloud Run free tier, no min-instances=1

Architecture summary — CLIP local pipeline

┌─────────────────────────────────────────────────────────────────────┐
│  Frontend (React + Vite, di Cloud Run)                              │
│  ├─ KasirScreen → CariByFotoModal (Camera / Upload / Drag-drop)     │
│  ├─ Client compress (canvas, 1024px, q=75)                          │
│  └─ POST multipart/form-data → backend                              │
└────────────────────────────┬────────────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────────────┐
│  Backend Go (Cloud Run, free tier, no min-instances=1)              │
│  ├─ POST /api/products/search-by-photo                              │
│  │  ├─ Validate image (≤5MB, image/*)                               │
│  │  ├─ Preprocess: decode → resize 224x224 → normalize RGB float32  │
│  │  ├─ CLIP encoder ONNX (ViT-Base-32, 150MB, ~150ms CPU)          │
│  │  │  └─ In-process, no external API call                          │
│  │  ├─ pgvector similarity search → top 5 (threshold 0.70)          │
│  │  └─ Return JSON results (NO query_description)                   │
│  ├─ POST /api/products/index-photos (sama CLIP, kind='index')       │
│  └─ Log clip_inference_log (kind, latency_ms, status)               │
└────────────────────────────┬────────────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────────────┐
│  Supabase Postgres + pgvector                                       │
│  ├─ stock_photo_embeddings (sku, photo_path, embedding vector(512))   │
│  ├─ RPC search_products_by_embedding(query, threshold, limit)       │
│  └─ clip_inference_log (kind, latency_ms, status, called_at)        │
└─────────────────────────────────────────────────────────────────────┘

Zero calls ke: Gemini · OpenAI · Google APIs · any external AI provider

✓ Pro

  • Zero quota, zero rate limit
  • Latency ~150ms (vs 2s Gemini)
  • Privacy: foto stay di server kita
  • Free forever (server cost ada, tapi tidak per-call)

⚠ Trade-off

  • Akurasi label spec (mis. 6A vs 10A MCB) lebih rendah dari Gemini Vision
  • Cold start 5-10s di Cloud Run free tier
  • Effort +1 hari dev untuk ONNX integration

→ Future upgrade

  • Trigger kalau akurasi < 80% top-1 minggu 4 post-launch
  • Hybrid: CLIP (top-20) + Gemini Vision re-rank → top-5
  • Spec terpisah, +2 hari dev
