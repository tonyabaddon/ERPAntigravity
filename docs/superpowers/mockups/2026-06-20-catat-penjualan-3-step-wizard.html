Catatan Mockup + Recap Keputusan (A1–A4, B5–B9)
UX yang visible di mockup
  • Stepper: Step selesai hijau ✓ (clickable jump-back). Step current navy. Pending abu-abu locked.
  • Context recap bar di Step 2 + 3: ringkas pilihan sebelumnya, "Ubah" untuk jump-back.
  • Tidak ada ad-hoc customer. Tidak ada Walk-in Cash placeholder. Tips di search: cari pakai HP untuk repeat-buyer auto-detect.
  • "+ Customer Baru" inline form: nama + HP + perusahaan + alamat. Optional checkbox "Ajukan TEMPO" + 3 fields (limit, term, alasan optional). TEMPO fire customer_credit_activate approval; customer saved with allows_tempo=false sampai Owner approve.
  • Jasa hanya 2 jenis: Custom Panel + Wiring Panel. Pure-component sale valid.
  • Lump-sum jasa: qty=0 OK. Owner finalisasi via Rakit Lock.
  • Pre-order: stock boleh minus. Yellow chip per-row "⏳ PRE-ORDER · kurang N" + summary banner. Backend pass allow_negative_stock=true.
  • TEMPO context box (Step 3): limit/outstanding/sisa real-time. Over-limit → Simpan disabled.
  • Banner ⚠️ Step 2 & 3: "mengandung jasa lump-sum → WIP + Owner Lock".
  • Post-save: existing SalesInvoicePDF.tsx. Aksi: Cetak Printer Biasa, Cetak Dot Matrix, Bagikan WA, Download PDF. "+ Catat Penjualan Lagi" reset wizard.
Backend Prereqs (off-mockup, perlu disiapkan)
  • Migration: ALTER TABLE customers ADD COLUMN address TEXT
  • Migration: recordSale + create_tempo_invoice + insertWipWithRakit dapat new param p_allow_negative_stock BOOLEAN DEFAULT false; relax stock-check ketika true.
  • Migration: drop stock_lots CHECK qty_remaining >= 0 kalau ada.
  • New RPC: reject_customer_credit_activate(p_request_id, p_reason).
  • Modify record_pi body: insert audit preorder_fulfilled ketika SKU yang masuk punya stock balance pre-call < 0 (FIFO oldest order_id).

  • Dashboard: card baru "Recent pre-order fulfillments (last 7 days)" + "Notify WA" button per row (manual).
  • Stock Manager: negative stock sudah tampil merah (existing).
  • EditOrderModal: stays compatible.

  • ApprovalInboxScreen: tambah dispatch arm + new CustomerCreditActivateApprovalRequestRow component.
