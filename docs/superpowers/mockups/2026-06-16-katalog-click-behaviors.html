↑ Baris MCB "membuka" panel foto di bawahnya · baris-baris lain "ter-push" ke bawah

✓ Pro

  • Tidak ada modal/overlay — paling "non-disruptive"
  • User bisa expand banyak baris sekaligus untuk bandingin foto
  • Gak butuh komponen Lightbox

✗ Con

  • Baris-baris di bawahnya ter-push, posisi visual berubah
  • Foto kecil (terbatas lebar tabel), jelek untuk produk yang foto-nya detail
  • Susah show gallery multi-foto dengan layout yang bagus
  • Tabel jadi "tidak rapi" kalau banyak baris di-expand bersamaan

Quick decision matrix

Skenario user 1. Lightbox 2. Tab Baru 3. Inline
"Foto-nya yang mana ya, pastikan barang yang benar" ★ Cepat Overkill ★ Cepat
"Bandingin 2-3 foto produk sekaligus" Tutup-buka modal ★ Multi-tab ★ Multi-expand
"Mau lihat semua foto produk (gallery)" ★ Gallery view Detail page Sempit
"Mau edit produk setelah lihat foto" Klik tombol "tab baru" ★ Langsung Klik link "detail"
Posisi scroll tabel tersimpan? ★ Ya ★ Ya (tab asal) ★ Ya
Implementasi effort Sedang (1 komponen baru) ★ Rendah (re-use) Sedang (state per row)
