Catatan + Recap Keputusan
Locked decisions
  • 2 entry points terpisah: salesLanding punya "+ Sales Invoice" + "+ Sales Order".
  • Rename: "Catat Penjualan" → "Sales Invoice"; new "Sales Order" untuk penawaran.
  • Konversi: SO → wizard pre-filled di Step 3, items editable, payment method + ongkir + alamat diisi saat convert. SO original preserved sebagai history (status=CONVERTED).
  • Stok: SO tidak menyentuh stok. Movement hanya saat SI dibuat.
  • Step 3 Quote-mode light: hanya catatan/syarat + total subtotal. Ongkir + alamat pengiriman diisi nanti saat convert ke SI (operator + customer biasanya finalize logistik bareng-bareng saat sudah deal).
  • + Produk Baru inline di Step 2 (shared antara SO + SI). Lite-create: nama + kategori + unit + harga jual + HPP. Stok awal 0 (semua gudang) → pesanan otomatis pre-order. Foto/specs lengkap di-set nanti via Produk & Stok screen.
  • Expiry: no auto-expire. Manual close (button + reason field).
  • Listing: sidebar menu baru "Penawaran" → halaman dedicated "Daftar Penawaran".
  • Implementation: new sales_orders table + extend wizard dengan mode='quote' prop + new insertNewProduct wrapper.
