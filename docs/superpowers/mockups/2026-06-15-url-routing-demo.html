Demo — "Buka di Tab Baru" URL Routing

Sidebar di atas pakai pattern <a href> + SPA click handler. Coba interaksi di bawah supaya feel-nya nyambung.

🎯 Coba sekarang:

  • Click biasa sidebar item → halaman ganti in-place, URL bar ikut update, browser back/forward jalan
  • Ctrl+click (Windows/Linux) atau ⌘ Cmd+click (Mac) → browser buka tab baru
  • Middle-click (klik tombol scroll mouse) → browser buka tab baru
  • Right-click → context menu native browser muncul "Open in new tab" / "Open in new window"
  • Pencet F5 / refresh setelah pindah screen → tetap di screen yang sama (TIDAK balik ke dashboard)
  • Pencet browser back button setelah pindah beberapa screen → kembali ke screen sebelumnya
  • Paste URL ?screen=pelanggan di tab baru → langsung buka Pelanggan

🔍 Logic snippet yang dipakai demo ini

// SAMA dengan handleSPAClick() di spec
function handleSPAClick(e, screen) {
  // Modifier key apapun = let browser handle natively
  if (e.ctrlKey || e.metaKey || e.shiftKey || e.altKey) return;
  // Bukan left-click = let browser handle (middle-click = button 1)
  if (e.button !== 0) return;
  // Plain left-click = SPA navigate
  e.preventDefault();
  navigate(screen);
}

function navigate(screen) {
  history.pushState({}, '', '?screen=' + screen);
  renderScreen(screen);
}

// Browser back/forward
window.addEventListener('popstate', () => {
  renderScreen(getScreenFromURL());
});
