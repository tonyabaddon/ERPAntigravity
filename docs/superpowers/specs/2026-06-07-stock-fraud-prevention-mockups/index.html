Phase 3b

Kasir — Shift · Override · Refund

Value / Manfaat

  • 🕐 Shift buka/tutup dengan kas pembuka + hitung fisik laci.
  • 🔒 Harga line item terkunci default · Ubah harga → approval Owner (PIN/WA).
  • 📉 Price floor backstop — bahkan approved override tidak boleh di bawah HPP.
  • ↩️ Refund selalu butuh Owner approval — refund = vektor fraud tertinggi, tidak ada auto.
