Design system: Inter / slate / emerald / amber / blue / rose Base font 14px v2: bahasa diperjelas, "commit" → "selesai/setujui"
State A — Admin view, status in_progress (TANPA LIHAT SISTEM)
Login sebagai admin/staff (role ≠ Owner). Tidak boleh lihat Sistem, Selisih, Total Selisih.
Yang berbeda dari sekarang: (1) Header kanan: badge "Tanpa Lihat Sistem" menggantikan "Total Varians". (2) Per baris: kolom "Sistem N", "Selisih qty", dan "Selisih Rp" hilang sepenuhnya — input field jadi lebih lebar. (3) Backend RPC mengganti system_qty_snapshot & variance jadi NULL untuk non-Owner saat in_progress. (4) Tombol bawah: "Kirim ke Owner untuk Disetujui" (sebelumnya "untuk Commit").

Catatan audit — penghitung & saksi untuk SETIAP opname
Setiap sesi opname yang berakhir (Selesai Otomatis ATAU Disetujui Owner) menulis row di audit_log. Owner bisa cek kapan saja siapa yang menghitung dan siapa saksinya.
Yang dijamin: tidak ada opname yang bisa "lewat" tanpa jejak. Counter (penghitung) + Witness (saksi) selalu tercatat dengan user_id + timestamp. Dua event types: opname_auto_commit untuk path auto, dan opname_owner_commit untuk path persetujuan Owner.
