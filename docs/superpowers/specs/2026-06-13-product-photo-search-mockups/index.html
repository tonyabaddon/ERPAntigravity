Change A: Generic fallback

Kategori tidak ada di CATEGORY_SPECS → pola Aksesori (1 textarea). Tenant elektrik tetap dapat Panel/MCB/Kabel/Aksesori siap pakai.

Change B: tenant_id kolom

tenant_id UUID NULL di 3 registry tables. Saat ini NULL (global). Saat multi-tenant rollout: backfill + RLS filter, no data migration risk.

lightbulb Schema Builder per tenant (UI tenant admin define field-field sendiri per kategori) = spec mandiri terpisah saat tenant non-elektrik onboard dengan kebutuhan konkrit.
