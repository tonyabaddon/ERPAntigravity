Design Section 5 of 5: React Integration & Sales Inbox Wiring

How the existing React screens connect to real Supabase data and live updates

What changes in each existing screen

💬 SalesInboxScreen.tsx — biggest change
❌ Currently (simulated)
  • Static INITIAL_CHATS from initialData.ts
  • No connection to WhatsApp numbers
  • No real-time updates
  • Admin messages don't go to WhatsApp
  • No media upload support
✅ After wiring
  • Loads from conversations + messages tables
  • Realtime subscription: new messages append live
  • Admin reply → INSERT to messages → Go daemon detects change → sends via WA
  • AI↔Admin toggle → UPDATE conversations.state
  • Media upload → Supabase Storage → messages.media_url
How admin reply reaches WhatsApp:
Admin types in Sales Inbox → React INSERTs row into messages (sender: "admin") → Supabase fires Realtime event → Go daemon has a separate DB listener subscribed to messages INSERT where sender="admin" → Go picks it up → whatsapp/sender.go sends the text to the customer's phone via whatsmeow.
📊 DashboardScreen.tsx — new orders panel added
PENDING queue
Live list of BOOKED orders waiting for admin to input shipping fee + approve
Approve flow
Admin inputs shipping fee → clicks Approve → React UPDATEs orders.status + shipping_fee
Invoice blast
Go daemon detects APPROVED status → generates invoice → sends WA message to customer automatically
Invoice WA message includes: customer name, order items, subtotal, shipping fee, total, bank account details, payment deadline (2×24 hours from approval).
🤖 WhatsappAiScreen.tsx — smaller changes
❌ Currently
  • Numbers stored in localStorage only
  • QR/pairing is fake simulation
  • Sandbox uses local keyword matching
  • Connection status is static
✅ After wiring
  • Numbers loaded from whatsapp_numbers table
  • QR/pairing triggers real whatsmeow flow via Go
  • Sandbox removed — real conversations in Sales Inbox
  • Connection status live via Realtime

Rich media uploads in Sales Inbox (PDF, Images, Excel, Word)

Upload flow (admin sends media to customer):
Admin clicks paperclip → file picker → React uploads file to Supabase Storage bucket chat-media → gets public URL → INSERTs messages row with media_url + media_type → Go daemon detects INSERT → downloads file from Storage URL → sends via whatsmeow SendMedia() to customer WA.
Receive flow (customer sends media to AI):
Customer sends image/doc → whatsmeow receives media event → Go downloads media → uploads to Supabase Storage → INSERTs messages row with media_url → Sales Inbox shows media preview via Realtime → AI sends acknowledgement text: "Dokumen Anda telah kami terima. Tim teknis akan meninjau dan menghubungi Anda." → auto-escalates to BUTUH_ADMIN.

New shared hook: useRealtimeConversations()

// src/hooks/useRealtimeConversations.ts
// Single hook used by SalesInboxScreen + DashboardScreen

export function useRealtimeConversations() {
  // 1. initial load from Supabase
  // 2. subscribe: messages INSERT → append to correct conversation
  // 3. subscribe: conversations UPDATE → update state/status badge
  // 4. subscribe: orders INSERT/UPDATE → update dashboard queue
  // 5. cleanup subscriptions on unmount
  return { conversations, orders, sendAdminMessage, toggleAiControl }
}
