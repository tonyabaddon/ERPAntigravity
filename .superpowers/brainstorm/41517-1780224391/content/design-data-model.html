Supabase Realtime — what React subscribes to

Sales Inbox
Subscribes to messages INSERT
Subscribes to conversations UPDATE (state changes)
→ Live chat bubbles + status badge updates
Dashboard / Orders
Subscribes to orders INSERT + UPDATE
→ New PENDING orders appear instantly
→ Status changes reflect in real time
WhatsApp AI Screen
Subscribes to whatsapp_numbers UPDATE
→ Connection status badge goes live
→ No more manual refresh needed
Row-Level Security (RLS) policy summary:
• messages, conversations, orders: Go daemon has INSERT/UPDATE via service key (bypasses RLS). React reads via anon key — SELECT only, scoped to authenticated admin session.
• orders: React can UPDATE shipping_fee and status (for admin approval) only — all other fields are read-only from frontend.
• stock_items: existing table, unchanged — React has full CRUD as today.
