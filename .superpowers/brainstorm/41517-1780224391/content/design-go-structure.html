Single message processing flow — what happens in Go when a customer sends "halo"

1
whatsapp/handler.go receives WA event → extracts senderPhone, text, waNumberId. Skips if IsFromMe or empty text. Runs rules engine first (fast, zero LLM cost).
2
rules/escalation.go checks for wiring/custom keywords. If matched → immediately insert ESCALATED_WIRING system message, update conversation state, send WA handover reply. Stop here.
3
db/conversations.go GetOrCreate conversation row for senderPhone + waNumberId. Load collected_data, state, language. Insert incoming message into messages table → Realtime pushes it to Sales Inbox instantly.
4
engine/machine.go selects system prompt for current state from prompts.go. Passes prompt + last 10 messages + collected_data + relevant stock context to Gemini.
5
gemini/client.go calls Gemini API with response_mime_type: "application/json". Returns structured JSON. engine/parser.go unmarshals + validates: if parse fails → fallback reply + log error (no crash).
6
engine/machine.go transitions state: merges new fields into collected_data, determines nextState. If next_action: "ESCALATE" → override nextState to ESCALATED_ADMIN.
7
db/conversations.go UpdateState + UpdateCollectedData. db/messages.go InsertMessage (sender: "ai"). State is persisted before sending WA reply — daemon restart safe.
8
If state just became BOOKED: db/orders.go CreateOrder → scheduler/timeout.go Schedule(orderId, 48hrs). Order appears in Dashboard as PENDING via Realtime.
9
whatsapp/sender.go sends AI reply text via whatsmeow. Done. Total latency target: < 3 seconds end-to-end.

Daemon restart safety — what happens if the server reboots

Conversation state
State is written to Supabase before every WA reply. On boot, conversations.go loads all non-terminal conversations from DB. The state machine resumes exactly where it left off.
Timeout goroutines
On boot, scheduler/timeout.go RestoreOnBoot() queries all BOOKED orders where booking_expires_at is in the future and re-schedules their goroutines. No bookings are lost on restart.
