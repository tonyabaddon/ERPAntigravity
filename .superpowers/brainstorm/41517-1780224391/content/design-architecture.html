Key design decisions baked in

Go daemon is the only writer
Only the Go daemon writes to conversations, messages, and orders. React is read-only on these tables (via RLS policies). Prevents data conflicts.
State persisted after every transition
Every state machine step writes to Supabase before replying to WhatsApp. If the daemon restarts, it reads conversation state from DB and resumes — no lost orders.
Admin writes go through React → Supabase
When an admin types in Sales Inbox or approves an order, React writes directly to Supabase. The Go daemon detects the change via a DB subscription and resumes sending on WhatsApp.
Gemini never called from React
All LLM calls go through the Go daemon — the Gemini API key is server-side only. React never touches Gemini directly.
